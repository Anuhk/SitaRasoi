# SitaRasoi
# 🍽️ Sita Rasoi — Traditional Indian Vegetarian Cuisine

A responsive restaurant website inspired by India's rich culinary traditions, celebrating authentic vegetarian food through a warm, elegant, and culturally inspired design.

## 🌐 Live Website

**Live Demo:** [https://sitarasoi.netlify.app/]

## 📖 About the Project

Sita Rasoi is a restaurant website concept created to showcase a traditional Indian vegetarian dining experience. The design combines earthy colors, Hindi typography, and a clean layout to reflect the warmth of Indian hospitality.

The website brings together regional dishes from different parts of India, making it easy for visitors to explore the menu and learn about the restaurant.

## ✨ Features

- **Home:** A welcoming hero section featuring Hindi text and traditional Indian-inspired styling.
- **Our Story:** A section highlighting the restaurant's values and cultural identity.
- **Regional Menu:** 13 food categories representing different Indian states and regions.
- **Contact Form:** Fields for name, email address, subject, and query description.
- **Smooth Navigation:** Smooth scrolling between sections through the navigation bar.
- **Responsive Design:** Layout adjustments for smaller screens.


## 🛠️ Technologies Used

- HTML5 — Website structure and content
- CSS3 — Styling, layouts, responsive design, and hover effects


## 🍛 Menu Highlights

The menu showcases regional vegetarian specialties, including:

- **Maharashtra:** Misal Pav
- **Gujarat:** Gujarati Thali
- **Rajasthan:** Dal Baati Churma
- **Punjab:** Amritsari Kulcha
- **Uttar Pradesh:** Banarasi Tamatar Chaat
- **West Bengal:** Shukto
- **Bihar:** Litti Chokha
- **Karnataka:** Bisi Bele Bath
- **Odisha:** Dalma
- **Kerala:** Appam with Vegetable Stew
- **Andhra Pradesh:** Gutti Vankaya
- **Tamil Nadu:** Ven Pongal

## 🎨 Design Approach

The visual identity of Sita Rasoi is inspired by traditional Indian aesthetics:

- Deep maroon and warm cream colors
- Hindi typography and culturally inspired text
- Terracotta accents
- Clean menu cards and spacious layouts
- Subtle hover interactions

The goal is to create a welcoming digital experience that connects regional Indian cuisine with a modern web design.
